The Ferneau app

One TypeScript codebase that builds for iOS, Android and the web. This is the real app, exported for the browser and running live in the phone frame. Tap around: it shares its account, bag and orders with the website and the admin.

  • ✓Onboarding, login & sign-up with a demo account and guest mode
  • ✓Catalogue, search & filters: category, hair type, concern, sort, in stock
  • ✓Product pages, wishlist and bag with coupon ROOTS10 and free-shipping rule
  • ✓Checkout with a demo payment gateway: UPI, test card 4242…, cash on delivery
  • ✓Order history and live tracking: change a status in the admin and watch it move

Run it on a phoneSource: Expo SDK project in TypeScript. npx expo start opens it in Expo Go on iOS and Android; npx expo export -p web builds this browser version. A signed Android APK (EAS Build) is the next step.
