# Ferneau — credits

Concept project by Zyqor Studio. Ferneau is a fictional brand; no products, reviews or orders are real.

## Imagery
- Every product, bottle, tube, jar, leaf, rosemary sprig, water drop and bubble is modelled in code with three.js. Product images and the no-WebGL poster are our own renders of those models (own work, MIT). No stock photos, no generated images.

## Code libraries
- three.js r170 — MIT License — https://github.com/mrdoob/three.js (RoomEnvironment and OrbitControls from three/examples, MIT)
- Mobile app: React Native, Expo, React Navigation, AsyncStorage, @expo/vector-icons (Feather icons) — MIT License

## Fonts

- DM Sans — Colophon Foundry / Google — SIL Open Font License 1.1 — via Fontsource / Google Fonts

## Data
- Catalogue, prices, ratings and orders are sample data written for this concept. Ratings are labelled "sample ratings" everywhere.
